📌 Project Overview
This project is a Calculator Web Application developed as part of the Oasis Infobyte Web Development Internship (OIBSIP) - Level 2 Task 1. The calculator performs basic arithmetic operations such as addition, subtraction, multiplication, and division through an interactive and user-friendly interface.
The application is built using HTML, CSS, and JavaScript, providing a responsive design and smooth user experience.

🚀 Features
Basic Arithmetic Operations
Addition (+)
Subtraction (-)
Multiplication (×)
Division (÷)
Clear (C) Function
Delete (⌫) Function
Decimal Number Support
Responsive Design
Interactive User Interface
Real-Time Input Display

⚙️ How It Works
Users click the calculator buttons to enter numbers and operators.
The entered expression is displayed on the screen.
Pressing "=" evaluates the expression.
The result is displayed instantly.
Users can clear the screen or delete individual characters.
